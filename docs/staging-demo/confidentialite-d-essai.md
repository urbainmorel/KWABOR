# Confidentialité du compte d’essai Kwabor

Ce document décrit le test individuel dans **Kwabor Staging**. L’application utilise
l’adresse de test pour envoyer le code d’inscription, les champs de profil d’essai pour
créer le compte et ses préférences, ainsi que les identifiants des fiches ajoutées aux favoris.

Les favoris sont associés au compte d’essai. Le mainteneur peut les consulter
et les retirer dans l’application. L’accès aux données du compte suit les règles
d’authentification et d’autorisation du staging.
